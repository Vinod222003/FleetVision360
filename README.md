# FleetVision 360

FleetVision 360 is a fleet management and analytics platform designed to monitor vehicles, deliveries, fuel consumption, and maintenance activities.

## Features

- Dashboard KPIs
- Live Fleet Monitoring
- Fleet Status
- Fleet Map
- Route Management
- Fuel Records
- Fuel Analytics
- Maintenance Records
- Delivery Performance

## Technologies

- Python
- FastAPI
- SQLite
- React
- Vite
- Recharts
- Leaflet
- SQL
